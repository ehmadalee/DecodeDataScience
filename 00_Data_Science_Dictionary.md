# 📊 Data Science & Pandas Glossary

A simple, beginner-friendly glossary of key terms used in data analysis, Pandas, and NumPy.

---

## A

- **Algorithm** – A step-by-step set of instructions to solve a problem.
  *Example: A recipe for baking a cake is an algorithm — follow the steps in order to get the result.*
- **API** – A way for two programs to talk to each other.
  *Example: A weather app uses an API to ask a weather service "what's the temperature today?" and gets an answer back.*
- **Array** – A list of items (usually numbers) stored together, all the same type.
  *Example: A row of lockers numbered 1 to 10, each holding one item — that's like an array.*
- **Axis** – Direction along which you work in a table: rows or columns.
  *Example: Adding up marks "across" each student (row-wise) vs adding up marks "down" each subject (column-wise).*

## B

- **Boolean** – A value that's either True or False.
  *Example: "Did the student pass? Yes" → True. "No" → False.*
- **Broadcasting** – A NumPy trick that lets you do math on data of different sizes without writing loops.
  *Example: If every student in a class gets 5 bonus marks added to their score, you don't add it one-by-one — broadcasting adds it to everyone at once.*

## C

- **Correlation** – A measure of how two things change together.
  *Example: Students who study more hours often get higher marks — that's a positive correlation.*
- **CSV** – A simple text file format where data is separated by commas, like a basic spreadsheet.
  *Example: A file listing "Name, Age, City" for each student, one line per student.*
- **Column** – A vertical set of values in a table, representing one feature/variable.
  *Example: In a class record sheet, the "Age" column shows every student's age.*

## D

- **Data** – Raw facts or numbers you collect or work with.
  *Example: A list of exam scores: 85, 90, 76, 60.*
- **Dataset** – A collection of related data, organized in rows and columns.
  *Example: A full spreadsheet of every student's name, age, and marks.*
- **DataFrame** – A table-like structure in Pandas with rows and columns.
  *Example: Think of it as an Excel sheet, but one you can control with code.*
- **Dimension** – The number of directions data extends in (1D = list, 2D = table, 3D = cube).
  *Example: A single row of numbers is 1D. A full spreadsheet with rows and columns is 2D.*
- **Data Type** – The kind of value something is (number, text, true/false).
  *Example: "25" is a number, "Ali" is text, and "Pass/Fail" is true/false type data.*
- **Duplicate** – A row or value that appears more than once in data.
  *Example: If the same student's record accidentally appears twice in a list, that's a duplicate.*

## F

- **Feature** – A single measurable property or column used in analysis.
  *Example: In a student dataset, "Age," "Marks," and "City" are each a feature.*
- **Filter** – Picking out only the rows that match a certain condition.
  *Example: Showing only students who scored above 80 marks.*
- **Function** – A reusable block of instructions that performs a task.
  *Example: A calculator's "+" button is like a function — you give it numbers, it gives you the sum.*

## G

- **GroupBy** – Splitting data into groups based on a value, so you can summarize each group.
  *Example: Grouping students by "City" to find the average marks in each city.*

## H

- **Head** – Viewing just the first few rows of a dataset.
  *Example: Looking at only the top 5 names on a long class list to get a quick preview.*

## I

- **Index** – The labels used to identify rows in a table.
  *Example: In a class list, roll numbers 1, 2, 3... act as the index for each student.*

## J

- **Join** – Combining two tables together based on a common column.
  *Example: Merging a "Student Info" table with a "Student Marks" table using the "Roll Number" they both share.*

## K

- **Key** – A column used to uniquely identify or match data.
  *Example: "Roll Number" is a key because no two students share the same one.*

## L

- **Library** – A collection of pre-written code you can reuse.
  *Example: Like borrowing a toolkit instead of building every tool yourself — Pandas and NumPy are libraries.*

## M

- **Mean** – The average of a set of numbers.
  *Example: Marks of 80, 90, 70 → mean = (80+90+70)/3 = 80.*
- **Median** – The middle value when numbers are sorted.
  *Example: Marks 60, 70, 90 → median = 70 (the middle one).*
- **Mode** – The value that appears most often.
  *Example: Shoe sizes 7, 8, 8, 9 → mode = 8 (it repeats the most).*

## N

- **NaN** – Stands for "Not a Number," used to show missing or unknown data.
  *Example: If a student didn't attend an exam, their score might be recorded as NaN instead of a number.*
- **NumPy** – A Python library for fast math and working with lists of numbers.
  *Example: Used when you need to quickly calculate the average of thousands of numbers.*

## O

- **Outlier** – A value that's very different from the rest of the data.
  *Example: If most students scored 60-90 but one scored 5, that score is an outlier.*

## P

- **Pandas** – A Python library for working with tables of data.
  *Example: Used to open a CSV file and look at it like a spreadsheet inside your code.*
- **Pivot Table** – A table that summarizes and rearranges data to see patterns easily.
  *Example: Turning a long list of sales records into a summary showing total sales per city per month.*

## Q

- **Query** – A question you ask your data to filter or find something specific.
  *Example: Asking "show me all students older than 18" is a query.*

## R

- **Row** – A horizontal set of values in a table, representing one record.
  *Example: One student's full record — name, age, marks — makes up one row.*

## S

- **Series** – A single column of data with labels.
  *Example: Just the "Marks" column from a student dataset, on its own, is a Series.*
- **Shape** – The size of data in terms of rows and columns.
  *Example: A class of 30 students with 4 columns (Name, Age, Marks, City) has a shape of (30, 4).*
- **Slice** – Taking a smaller piece out of a list or table.
  *Example: Picking only the first 5 students from a class list of 30.*
- **Standard Deviation** – A measure of how spread out numbers are from the average.
  *Example: If everyone in a class scored close to 80, standard deviation is low. If scores range wildly from 20 to 100, it's high.*

## T

- **Transpose** – Flipping rows into columns and columns into rows.
  *Example: Turning a table where subjects are columns into one where subjects become rows instead.*

## U

- **Unique** – Values that appear only once, with no repeats.
  *Example: A list of all the different cities students come from, with no city repeated.*

## V

- **Variable** – A named container that holds a value, which can change.
  *Example: A box labeled "age" that currently holds the number 20, but could be changed later.*
- **Vectorization** – Doing math on a whole list at once instead of one item at a time.
  *Example: Adding 10 marks to every student's score in one step, instead of going student by student.*
- **Visualization** – Turning data into charts or graphs so it's easier to understand.
  *Example: Showing student marks as a bar chart instead of a long list of numbers.*
